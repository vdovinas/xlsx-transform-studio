# XLSX Studio

Локальное приложение для Windows x64: преобразует XLSX и CSV в XLSX по настраиваемым правилам. Интерфейс работает на Tauri 2 и системном WebView2, обработка таблиц — в отдельном процессе Java с Apache POI и Commons CSV.

## Сборка из исходников

Для сборки нужны:

- Windows x64 и PowerShell;
- JDK 17 (полный комплект, включая `jlink`);
- Apache Maven 3.8.6 или новее;
- Node.js 24 с npm;
- Rust stable с целью `x86_64-pc-windows-msvc` и Visual Studio Build Tools с компонентами C++ и Windows SDK;
- Microsoft Edge для проверок интерфейса;
- доступ в интернет для загрузки зависимостей Maven, npm, Cargo и средств упаковки.

Установите инструменты и добавьте их в `PATH`. `JAVA_HOME` должен указывать на JDK 17. Проверьте в новом окне PowerShell:

```powershell
java -version
jlink --version
mvn -version
node --version
npm --version
cargo --version
```

Скачайте или клонируйте репозиторий, откройте PowerShell в его корне и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\package.ps1
```

Команда проверяет форматирование Java, запускает Java-тесты, собирает JAR, создаёт встроенную среду Java через `jlink`, устанавливает зависимости через `npm ci`, выполняет тесты обработчика и интерфейса, затем собирает установщик.

Результат для версии `1.0.0`, указанной в `package.json`:

```text
release/XLSX Studio_1.0.0_x64-setup.exe
```

Для сборки папки приложения без установщика:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\package.ps1 -Portable
```

Запуск: `release/portable/xlsx-studio.exe`. Для переноса на другой компьютер копируйте всю папку `portable`. На компьютере пользователя не нужны Java, Node.js или Microsoft Excel: Java включена в сборку. Нужен WebView2 Runtime: установщик загрузит его при отсутствии. Для переносной версии WebView2 должен быть установлен заранее. Для установки на компьютеры без интернета и без WebView2 нужно отдельно подготовить его офлайн-установку. Установщик не подписан цифровым сертификатом.

### Что хранится в репозитории

Исходники, готовые профили, `pom.xml`, `package.json`, `package-lock.json`, `package.ps1` и `src-tauri/` входят в Git. Локальные файлы для сборки заранее копировать не требуется.

Следующие папки исключены через `.gitignore` и создаются при сборке:

| Папка | Содержимое |
| --- | --- |
| `target/` | JAR, результаты Java-тестов, тестовая XLSX-книга и снимки интерфейса |
| `tools/` | Локальные кэши зависимостей, среда Java и обработчик для запуска из исходников |
| `node_modules/` | Инструменты Tauri и тестов интерфейса |
| `src-tauri/target/` | Сборка Rust и упаковщик Tauri |
| `release/` | Установщик и распакованное приложение |

`npm start` и `run.cmd` сами не собирают Java-обработчик. Перед первым запуском выполните `package.ps1` (можно с `-Portable`).

## Работа с приложением

1. Выберите XLSX или CSV. Для XLSX задайте лист и строку заголовков; для CSV — запись с заголовками, кодировку и разделитель. После изменения номера заголовков нажмите «Обновить столбцы». Приложение показывает названия столбцов, без предпросмотра результата.
2. Выберите профиль: «Сбербанк», «Точка», «Касса — доходы», «Касса — расходы» или «Новый профиль». Профиль выбирается вручную; загрузка CSV не заменяет текущие правила.
3. Откройте настройки кнопкой ⚙. Настройте выходные поля: порядок, название, исходный столбец, обязательность, тип (текст, число, дата) и формат ячейки Excel. Столбец можно указать по заголовку или позиции: `@A`, `@B` и далее. Пустые и повторяющиеся заголовки доступны по букве.
4. Добавьте преобразования и условия. Действия выполняются сверху вниз: удаление пробелов, изменение регистра, замена текста, извлечение регулярным выражением, константа, подстановка при пустом значении, классификация, преобразование в число или дату. Классификация выбирает первую совпавшую ветку; ветка без условий задаёт значение по умолчанию.
5. В «Фильтрах строк» задайте условия сохранения строк: все или хотя бы одно. Дополнительные группы выполняются вместе с основным фильтром. Пустые фильтры пропускают все строки.
6. В настройках выбирайте профили, создавайте пустые или копируйте текущий. Изменения автоматически сохраняются в коллекцию в папке данных приложения; «Сохранить» (`Ctrl+S`) сохраняет сразу. Названия должны быть непустыми и уникальными без учёта регистра и пробелов по краям. Кнопка отмены возвращает предыдущую структуру правил.
7. Вернитесь к преобразованию, нажмите «Преобразовать и сохранить XLSX» и выберите путь результата. Обработку можно отменить.

При ошибке преобразования ячейка сохраняет исходное значение, получает розовую заливку и примечание с причиной и номером исходной строки. При отсутствии исходного столбца значение остаётся пустым с пояснением. Ошибка фильтра сохраняет строку с отметками ошибок.

Исходный файл перезаписать нельзя. Существующий результат заменяется после успешной обработки; интерфейс запрашивает подтверждение замены. Отмена или ошибка чтения сохраняет прежний результат.

### Форматы и ограничения

- Вход: один лист XLSX или один CSV за запуск. Выход: XLSX. XLS не поддерживается.
- Максимум 100 000 непустых строк данных. Оформление исходной книги не переносится.
- Формулы XLSX читаются по сохранённым результатам, без пересчёта. Перед загрузкой сохраните книгу в Excel или LibreOffice.
- CSV: UTF-8 с BOM или без него, Windows-1251; разделители — точка с запятой, запятая, табуляция. Кодировка и разделитель определяются автоматически или задаются вручную и сохраняются в профиле. Для неоднозначной кодировки выберите её явно. UTF-16 не поддерживается.
- CSV поддерживает кавычки, удвоенные кавычки и переносы внутри значений. Номера заголовков и строк считаются по логическим записям. Пустые записи пропускаются; некорректные кавычки и значения длиннее 32 767 символов останавливают обработку.
- Числа допускают пробелы и десятичную запятую. Для идентификаторов и номеров документов используйте текст: точность чисел Excel ограничена примерно 15 значащими цифрами.
- Стандартные входные даты: `dd.MM.yyyy`, `yyyy-MM-dd`, `dd/MM/yyyy`. Для других форматов добавьте действие «Преобразовать в дату» с шаблоном Java. Форматы Excel по умолчанию: `dd.mm.yyyy` для дат и `0.00` для чисел.
- Извлечение регулярным выражением возвращает первую группу в скобках или всё совпадение.

## Разработка и проверки

После подготовки полной сборки запустите приложение из исходников:

```powershell
npm start
```

Отдельные проверки из корня проекта:

```powershell
mvn -B -ntp "-Dmaven.repo.local=tools/m2" spotless:check verify
npm test
npm run test:ui
cargo test --manifest-path src-tauri/Cargo.toml
```

Тесты Node.js и интерфейса требуют `tools/engine/xlsx-desktop.jar`, встроенную Java в `tools/engine/runtime` и `target/electron-fixture.xlsx`. Их подготавливает `package.ps1`; тестовую книгу создают Java-тесты. После изменения Java-кода повторите полную сборку, чтобы обновить копию обработчика в `tools/engine`.

Тесты интерфейса проверяют редактирование правил, импорт XLSX и CSV, экспорт с отметками ошибок и сохраняют снимки в `target/interface-*.png`. Форматирование Java: `mvn spotless:apply`.

После сборки переносной версии `npm run test:tauri` проверяет запуск настоящего приложения в WebView2, загрузку профилей, валидацию и подписку на события. Снимок окна: `target/interface-tauri.png`. Системные диалоги выбора файлов эта проверка не открывает.

### Структура проекта

| Путь | Назначение |
| --- | --- |
| `src-tauri/src/main.rs` | Окно, системные диалоги, профили, запуск Java и отмена |
| `src-tauri/tauri.conf.json` | Параметры окна и упаковка ресурсов |
| `desktop/renderer/bridge.js` | Связь интерфейса с Tauri |
| `desktop/renderer/` | Интерфейс и редактор правил |
| `desktop/engine.cjs` | Запуск Java-процесса для тестов |
| `desktop/profile.cjs` | Проверка профилей в тестах Node.js |
| `src/main/java/local/xlsx/model/` | Модели профилей и правил |
| `src/main/java/local/xlsx/service/` | Чтение таблиц, применение правил и запись XLSX |
| `src/main/java/local/xlsx/repository/` | Хранение профилей |
| `src/main/java/local/xlsx/cli/` | JSON-протокол Java-обработчика |
| `src/main/resources/profiles.json` | Встроенные профили |
| `desktop/test/`, `src/test/` | Проверки приложения и обработчика |
